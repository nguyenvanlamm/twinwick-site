# twinwick-site

Landing page, privacy policy and support page for **Twinwick**, a candle-heap puzzle game for iPhone and iPad.

- Live: https://nguyenvanlamm.github.io/twinwick-site/
- Pages: `index.html`, `privacy.html` (App Store privacy policy URL), `support.html` (App Store support URL).
- Static HTML with inline CSS, no build step and no JavaScript. Served by GitHub Pages from the default branch.
- Screenshots in `shots/` and the icons come from the game repository (`design-demos/shots/`, `assets/logo/`).
